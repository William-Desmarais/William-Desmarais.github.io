Automated Syringe Filler

Designed an automated syringe filler for medical practitioners to reduce downtimes in high throughput vaccination clinics.

← Back to portfolio

Project Description

This project focused on automating the syringe filling process to support high-throughput vaccination clinics. The design reduces manual handling time, minimizes downtime between patients, and improves consistency and safety.

The system integrates precise fluid metering, automated syringe positioning, and a user interface for configuring batch sizes and volumes. Emphasis was placed on reliability, ease of sterilization, and a compact footprint for clinical environments.
